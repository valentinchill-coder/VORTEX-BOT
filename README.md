# VORTEX-BOT — Rewrite v2

This branch is a clean rewrite workspace.

Legacy application code has been removed from this branch. The production `main` branch is intentionally unchanged while the replacement is developed and tested.

## Rewrite goals

- Rebuild the Telegram bot with a clean modular architecture.
- Reimplement the verified moderation, ranks, economy, games, shop, market, profiles, quests, and private panel features.
- Add automated tests and validate each subsystem before deployment.

No production deployment should be made from this branch until the rewrite is complete and approved.
