# VORTEX BOT

Telegram-бот для базовой модерации одной или нескольких групп.

## Возможности первой версии

- приветствие новых участников;
- антифлуд: удаление сообщений при превышении лимита;
- предупреждения: `/warn`, `/warnings`, `/clearwarns`;
- мут: `/mute 10m`, `/unmute`;
- удаление участника: `/kick`;
- бан и разбан: `/ban`, `/unban ID`;
- статистика предупреждений: `/stats`.

Команды модерации нужно отправлять ответом на сообщение пользователя, кроме `/unban ID`.

## Локальный запуск

Требуется Python 3.10 или новее.

1. Создайте бота через [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Скачайте репозиторий на компьютер или сервер.
3. Установите зависимости:

   `python -m pip install -r requirements.txt`

4. Скопируйте `.env.example` в `.env` и укажите `BOT_TOKEN`.
5. Запустите:

   `python bot.py`

Локально бот использует long polling. Не публикуйте файл `.env` и токен бота.

## Бесплатный запуск на Render

Для Render Web Service используется webhook-режим. Если Render передаёт переменную `RENDER_EXTERNAL_HOSTNAME`, бот автоматически включает webhook и слушает порт из переменной `PORT`. Вручную задавать URL или webhook-секрет не требуется: секрет создаётся при запуске, а адрес берётся из Render.

Настройки сервиса:

- Runtime: Python
- Build command: `pip install -r requirements.txt`
- Start command: `python bot.py`
- Instance type: Free
- Environment variable: `BOT_TOKEN` — новый токен бота, добавленный через раздел Environment в Render. Не добавляйте токен в GitHub.

После создания сервиса дождитесь успешного Deploy. Проверка доступности: откройте корневой URL сервиса или путь `/healthz`; должен появиться текст `VORTEX BOT is running`.

### Ограничения бесплатного тарифа

- Render останавливает бесплатный Web Service после 15 минут без входящего трафика. При следующем webhook-запросе сервер должен запуститься, но обработка обновлений может задержаться.
- Telegram повторяет неуспешную доставку webhook, но не хранит обновления бесконечно (не более 24 часов).
- Файловая система бесплатного сервиса временная. SQLite-файл и все предупреждения/события в нём могут исчезнуть после остановки, перезапуска или нового деплоя.
- Бесплатный Render Postgres не является постоянным решением: его срок жизни — 30 дней.

Поэтому бесплатный запуск подходит для проверки и экспериментов, но не для надёжной модерации важной группы. Для постоянного хранения предупреждений понадобится внешняя база данных с подходящим бесплатным тарифом или платное постоянное хранилище.

## Добавление в группу

1. Добавьте бота в группу.
2. Назначьте его администратором.
3. Выдайте права на удаление сообщений, блокировку участников и ограничение участников.
4. Проверьте команды в отдельной тестовой группе.

Для команд владельца можно указать Telegram ID в `OWNER_IDS`, разделяя несколько ID запятыми. Администраторы самой группы тоже могут использовать команды модерации.

## Важно

Это стартовая версия. Антифлуд сейчас удаляет сообщения сверх лимита, но не выдаёт автоматический мут. Перед запуском в основной группе протестируйте права и команды в отдельной тестовой группе.
